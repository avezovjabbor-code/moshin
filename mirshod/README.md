# AVTOPOLIGON 3D - Mashinalar Poygasi & Drift (Mirshod Edition)

Bu veb-sayt zamonaviy **3D WebGL (Three.js)** texnologiyasi asosida yaratilgan superkarlar poygasi o'yini.

## 📁 Papkadagi Fayllar Ro'yxati:
- **`index.html`** — O'yinning asosiy bosh sahifasi (istalgan brauzerda ochiladi).
- **`style.css`** — Neon cyberpunk dizayn, spidometr va interfeys stillari.
- **`game.js`** — Poyga fizikasi, boshqaruv, to'qnashuvlar va o'yin mexanikasi.
- **`models.js`** — 3D avtomobillar (BMW M5, Malibu 2 Turbo, Gentra Tuned, Mercedes-AMG GT, Lamborghini, Bugatti, Damas) va shahar modellari.
- **`audio.js`** — Web Audio API protsedurali ovoz tizimi (Dvigatel, Nitro, Drift, Gudok, Musiqa).
- **`three.min.js`** — 3D grafik dvigateli (Internet bo'lmaganda ham 100% oflayn ishlash uchun).
